کسب‌هوش | راهنمای انتشار لندینگ و ورود روی GitHub Pages

این بسته مخصوص سایت نمایشی است و از یک پوشه ریشه شامل index.html و login.html و پوشه assets تشکیل شده است.

مراحل:
۱) فایل ZIP را روی کامپیوتر Extract کنید.
۲) در GitHub یک Repository جدید بسازید (برای GitHub Pages رایگان باید Public باشد).
۳) از Add file > Upload files محتویات پوشه استخراج‌شده را آپلود کنید؛ خود فایل ZIP را آپلود نکنید.
۴) دقت کنید index.html و login.html در ریشه Repository دیده شوند.
۵) وارد Settings > Pages شوید و Source را Deploy from a branch قرار دهید؛ Branch: main و Folder: /(root)، سپس Save.
۶) لینک سایت معمولاً https://USERNAME.github.io/REPO/ و لینک ورود https://USERNAME.github.io/REPO/login.html است.

هشدار: فایل‌های این بسته رابط کاربریِ نمایشی هستند و احراز هویت واقعی یا ثبت مالی انجام نمی‌دهند. روی GitHub Pages اطلاعات حساس منتشر نکنید.
